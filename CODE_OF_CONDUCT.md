# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment, personal attacks, and discriminatory language are not acceptable in issues, pull requests, or any other project space.

Report unacceptable behaviour to the maintainer, [@megamp15](https://github.com/megamp15), through a private GitHub message or a [private security advisory](https://github.com/megamp15/AUTOLAB/security/advisories/new) if the report is sensitive. Reports are handled confidentially.
